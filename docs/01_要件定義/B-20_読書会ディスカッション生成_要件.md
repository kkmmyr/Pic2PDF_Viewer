# B-20 読書会ディスカッション生成 — 要件定義

> 作成: 2026-05-13 / grill-me インタビューより

---

## 1. 目的とユーザー価値

1 冊の小説を Qwen に読み込ませ、**2 人のキャラクター（ペルソナ）が読書会のように語り合う対話**をリアルタイム生成する。

- **内容把握の補助**: 多角的な視点で本の主題・伏線・人物心理を整理する（受動体験）
- **エンタメ**: キャラクター同士の対話の面白さ自体を楽しむ

---

## 2. データモデル / スキーマ影響

| 項目 | 内容 |
|------|------|
| 新規ファイル | `kindle_novel/discussions/<bookName>/<timestamp>.json` |
| 既存 meta.json | **変更なし** |
| JSON 構造（案） | `{book, personas, turns: [{speaker, text}], partial: false, created_at}` |
| キャンセル時 | `partial: true` を付けて保存 → フロントでは保存しない（キャンセル = 保存なし） |

> **注意**: キャンセル時は保存しない（ユーザー指定）。`partial` フィールドは将来の拡張のみ想定。

## 4. UI / API

### 4.1 ページ構成（`/novel/discussion`）

1. **書籍選択**: 小説ライブラリから 1 冊選択
2. **ペルソナ設定パネル**（キャラクター A / B）
   - プリセット 3 軸（下記）から選択し組み合わせ可能
   - カスタム自由入力（名前 + 一言説明）も可
3. **発話数スライダー**: ユーザーが往復数を指定（例: 3〜20 往復）
4. **生成ボタン → SSE ストリーミング表示**
   - キャラクター A / B を交互に、1 発言ずつリアルタイム表示
   - 生成中はキャンセルボタンを表示
5. **履歴一覧**: 同じ本の過去生成ログを JSON から読み込み表示

### 4.2 プリセット定義（3 軸、組み合わせ自由）

| 軸 | 選択肢 |
|----|--------|
| 読書スタイル | 批評家 / ファン / 懐疑派 |
| 口調 | 敬語丁寧 / フランク / 関西弁風 |
| 視点 | 文学評論 / 感情重視 / ロジック重視 |

### 4.3 API（未確定、SSE を推奨）

```
POST /api/novel/discussion/generate
Body: {book_name, personas: [{name, style_description}, ...], num_turns: N}
Response: SSE ストリーム
  data: {"type": "turn", "speaker": "A", "text": "..."}
  data: {"type": "done", "saved_path": "kindle_novel/discussions/..."}
  data: {"type": "error", "message": "..."}
```

> API スタイルは実装時に確定。既存の `/novel/stream`（QA ストリーミング）と同パターンにする。

### 4.4 入力層

- **本文全体を Qwen 131k コンテキストに投入**
- トークン数を事前推計し、超過時は **エラーを返す**（サマリへの自動フォールバックなし）

---

## 5. エッジケース

| ケース | 対応 |
|--------|------|
| 本文が 131k ctx を超える大作 | 事前トークン推計 → エラーメッセージ表示。生成不可 |
| 生成中にユーザーがキャンセル | SSE 切断 → JSON 保存なし |
| 既存の討論履歴が 0 件 | 履歴セクションを空表示（エラーなし） |
| Qwen サーバーが停止中 | 既存 QA と同様のエラーハンドリング |

---

## 6. 失敗時の挙動

- トークン超過 → UI にエラートースト。再試行促す
- Qwen 接続エラー → UI にエラートースト。既存 QA と同じ表示
- 生成途中のキャンセル → 保存なし、UI はそのまま（生成済み分は残す）

---

## 7. スコープ外（やらないこと）

- 漫画・同人誌ソースへの対応（小説のみ）
- 3 人以上のマルチキャラクター
- ユーザーが会話に介入（コメント・方向指示）
- 生成済み対話の再編集
- B-20 で生成した対話を RAG に取り込む
