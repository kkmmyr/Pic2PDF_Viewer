# B-24 要件: Build + OCR 管理画面の集約（/novel/manage）

最終更新: 2026-05-13

## 背景・動機

現状は `/novel/ocr`（OCR 管理）と `/novel/build`（Full Build 管理）が別画面で、OCR → Full Build という処理の順序が UI から読み取れない。1 画面にタブで統合し、操作の流れを明示する。

## 決定事項

| 項目 | 決定 |
|---|---|
| 新 URL | `/novel/manage`（タブ付きの統合管理画面） |
| 旧 URL | `/novel/ocr` / `/novel/build` は廃止。リダイレクトなし（404） |
| サイドバー | 「OCR 管理」「本構築管理」の 2 項目 → 「構築管理」1 項目に統合 |
| タブ | OCR タブ（左/先）→ Full Build タブ（右/後）の 2 タブ |
| 全ジョブセクション | 各タブの下部に共通セクションを追加。OCR / Full Build / コンテキスト生成を混在表示。全状態（実行中・待機中・完了済み）を列挙 |

## スコープ外

- 旧 URL へのリダイレクト実装
- B-22 進捗詳細化（スピナー・チャンクカウンター）— 別タスクで後から追加
- OCR → Full Build を一括エンキューするボタン

## 実施順序

ページ集約（本タスク）を先に完了させ、B-22（進捗詳細化）はその後に実施する。

## UI 設計

```
└─────────────────────────────────┘
```
