# 4.3 作者・シリーズ整理 — 要件定義

> 2026-05-13 /grill-me セッションで確定

---

## 1. 概要と目的

小説ライブラリ（`novel` ソース）の各書籍に **著者・シリーズ名・巻番号・出版社（レーベル）・ASIN** を付与し、BookCard で表示できるようにする。

**解決したい問題**: 現状 `BookSummary.authors` フィールドはあるが値が空のまま。シリーズ順・著者名での把握ができない。

**入力手段は 2 つ**:
1. **手動入力**: BookCard の「編集」ボタン → BookMetaEditModal で 1 冊ずつ編集
2. **一括インポート**: Amazon デジタル購入履歴 CSV をアップロード → プレビュー確認 → 保存

---

## 2. 対象ソース

`novel` ソースのみ。`doujin` / `comic` への適用は **スコープ外**。

---

## 3. データモデル

### 3.1 MetaEntry 拡張（`backend/services/meta_store.py`）

既存フィールドに以下を追加（すべて `NotRequired`）:

```python
series_id:    NotRequired[str]        # シリーズ名（巻番号・レーベルを除いたタイトル幹）
volume:       NotRequired[int | None] # 巻番号（整数。単巻の場合は None）
publisher:    NotRequired[str]        # 出版社・レーベル（例: ビーズログ文庫）
asin:         NotRequired[str]        # Amazon ASIN（例: B009IMAVXC）
isbn:         NotRequired[str]        # ISBN（手動入力のみ。CSV には含まれない）
release_date: NotRequired[str]        # 発売日 ISO 形式（手動入力のみ）
```

`authors` は既存フィールド（`list[str]`）を流用。CSV インポート時に上書きする。

### 3.2 永続化先

`backend/data/meta/novel/meta.json`（既存 meta_store の `novel` キー）。meta_store の `load_meta` / `save_meta` を経由する。

---

## 4. UI 仕様

### 4.1 BookCard 編集ボタン

- OCR 済み／未済みを問わず全書籍に「編集」ボタンを追加
- クリックで `BookMetaEditModal` を開く
- モーダルフィールド: 著者（タグ入力/カンマ区切り）、シリーズ名、巻番号、出版社、ASIN、ISBN、発売日
- 保存: `PATCH /api/meta/novel/{book_key}` を呼び即時反映

### 4.2 小説ライブラリ画面（`NovelDbPage`）に CSV インポートボタン追加

- ライブラリセクションのヘッダー付近に「Amazon CSV インポート」ボタンを配置
- クリックで `AmazonCsvImportPage`（専用ページ または モーダル） を開く
- **フロー**:
  1. CSV ファイルを選択（ファイルピッカー、複数ファイル対応）
  2. バックエンドへ `POST /api/novel/meta-import/preview` で送信
  3. プレビューテーブル表示（書名・著者・シリーズ・巻番号・出版社・ASIN + マッチ結果）
  4. 未マッチ行は手動で対応書籍を選択
  5. 「保存」ボタンで `POST /api/novel/meta-import/apply` を呼び meta.json に書き込み

### 4.3 BookCard メタ表示

- `book.authors` が空でなければ著者名を表示（現行ロジック流用）
- `book.series_id` と `book.volume` があれば「シリーズ名 N 巻」を表示
- `book.publisher` があれば出版社を表示

---

## 5. バックエンド API

| エンドポイント | メソッド | 説明 |
|---|---|---|
| `/api/meta/novel/{book_key}` | `PATCH` | 1 冊のメタを部分更新（手動編集） |
| `/api/novel/meta-import/preview` | `POST` | CSV アップロード → マッチ結果 JSON を返す（DB 書き込みなし） |
| `/api/novel/meta-import/apply` | `POST` | プレビュー結果を確認済みとして meta.json に反映 |

既存の `GET /api/meta/{source}` 経由でフロントに配信される `MetaEntry` に新フィールドが含まれる形（後方互換: `NotRequired` なので旧データは null 扱い）。

---

## 6. Amazon CSV パース仕様

対象ファイル: `amazon-order_digital_*.csv`（UTF-8 with BOM / Shift-JIS 両対応）

| CSV 列 | 抽出内容 | 処理方法 |
|---|---|---|
| `商品名` | タイトル全体（例: `おこぼれ姫と円卓の騎士 1 (ビーズログ文庫)`） | 末尾の `(レーベル名)` を `publisher` に、数字を `volume` に、残りを `series_id` に |
| `付帯情報` | 著者名（例: `[Kindle 版] 石田 リンネ, 起家 一子  販売: ...`） | `[Kindle 版] ` を除き `販売:` 前までをカンマ分割 → `authors` リスト |
| `商品URL` | ASIN（例: `https://...amazon.co.jp/dp/B009IMAVXC/...`） | `/dp/([A-Z0-9]{10})/` で抽出 → `asin` |

**書籍マッチング**:
- `商品名` が images/ サブディレクトリ名に部分一致（または逆方向）→ 自動割当
- 一致なし → プレビュー画面で「未マッチ」表示 → 手動でドロップダウン選択

- メタデータの一括エクスポート（CSV/JSON ダウンロード）
