### 13-2. ファイル名バリデーションのユーティリティ化（P2）

**問題**: 同じ正規表現が3ファイルで重複定義されており、エラーメッセージも微妙に異なる。

| ファイル | 行 | コード |
|---|---|---|
| `RenameDialog.tsx` | 4 | `const FORBIDDEN_RE = /[/\\:*?"<>\|]/;` |
| `CreateFolderDialog.tsx` | 4 | `const FORBIDDEN_RE = /[/\\:*?"<>\|]/;` |
| `MergeDialog.tsx` | 10 | `const INVALID_CHARS = /[/\\:*?"<>\|]/;` |

**改善案**: `frontend/src/utils/validation.ts` に集約する。

```ts
export function validateFileName(value: string, kind: 'file' | 'folder'): string | null {
    if (!value.trim()) return `${kind === 'folder' ? 'フォルダ名' : 'ファイル名'}を入力してください。`;
    if (FORBIDDEN_FILENAME_CHARS.test(value)) return '使用できない文字が含まれています: / \\ : * ? " < > |';
    return null;
}
```

**新規作成**: `frontend/src/utils/validation.ts`
**変更対象**: 上記3ダイアログ

### 15-4. auto_fill_service の view_count / last_viewed_at 消失バグ修正（**P1**）

update_meta_locked(source, lambda m, k=key, a=author: m.update({k: {"authors": [a]}}))

## 対象外（現状維持）

| 項目 | 理由 |
|---|---|
| `useLibraryManagement` のリネーム | 影響範囲が広い割に効果小 |
| `types/index.ts` の `BookMetaEntry` 拡張 | サークル名のみ管理の現行設計で十分 |
| SearXNG → DLsite 直接検索 | 既知の問題として記録済み。工数大のため別途判断 |
| API バージョニング | 現状シングルクライアント構成のため不要 |
