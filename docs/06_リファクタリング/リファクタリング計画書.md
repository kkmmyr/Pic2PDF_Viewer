#### Phase 55-6 — 全 SSE ルーターのログ欠落補完（**P2**: 観測性 / 旧: P3、2026-05-13 昇格・スコープ拡張）

**問題**: SSE の `event_stream` 内で `logger.exception` を呼んでいないルーターが 3 つに拡大:
1. `routers/novel_db.py:post_qa`（当初からの問題）— `event_stream()` の `except` で `str(e)` を SSE に流すだけ。
2. `routers/novel_discussion.py:generate_discussion`（B-20 追加・新規）— `except Exception as e:` で `logger.exception` 未呼出。
3. `routers/novel_build.py:get_stream`（§4.6 追加・新規）— try/except **自体が無い**。SSE 例外時はサーバ側ログなしで黙って切断される。

**改善案**: 全 SSE ルーターに統一して対応:
  1. 各 `event_stream()` の `except Exception as e:` 直後に `logger.exception("... SSE error: ...")` を追加。
  2. `novel_build.get_stream` は try/except を新規追加。
  3. SSE エンドポイントの docstring に「`@log_and_raise_500` 非適用理由（SSE ストリーム内で捕捉して SSE event + `logger.exception` で通知）」を明記。

**変更対象**:
- `backend/routers/novel_db.py`（`post_qa` L320 付近）
- `backend/routers/novel_discussion.py`（`generate_discussion` L104 付近）
- `backend/routers/novel_build.py`（`get_stream` / try/except 追加）

**新規作成**: なし
**完了条件**: `uv run pytest tests/test_router_novel_db.py tests/test_novel_discussion.py tests/test_router_novel_build.py -v` 通過。動作変更なし。

## 対象外（現状維持）

リスク・工数に対してメリットが小さい、または現行設計で十分な項目。

| 項目 | 理由 |
|---|---|
| Pydantic ↔ TS 型自動生成（openapi-typescript 等） | 工数大。手書き同期で運用継続 |
| `pdf_generator.execute_moves` と `file_manager` のロールバック共通化 | 対象（処理ファイル種・タイミング）が異なり、共通化メリット小 |
| `GEMMA_TOOL_DIR` の Windows パス依存デフォルト値 | Phase 8 で `.env` で上書き可能。Linux/Mac 開発予定なし |
| SearXNG → DLsite 直接検索 | 既知の問題として記録済み（Phase 12 時点で対象外維持） |
| `useLibraryManagement` のリネーム | 影響範囲が広い割に効果小 |
| `types/index.ts` の `BookMetaEntry` 拡張 | サークル名のみ管理の現行設計で十分 |
| API バージョニング | 現状シングルクライアント構成のため不要 |
