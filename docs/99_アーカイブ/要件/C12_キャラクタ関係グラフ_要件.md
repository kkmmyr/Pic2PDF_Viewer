# C-12 キャラクタ関係グラフ 要件

作成: 2026-05-15

---

## 目的・ユーザー価値

シリーズ新刊を読む際に前巻までの人物関係を一覧で把握する。
キャラ辞典（B-15）は個別カードで「A と B の関係」が俯瞰できないという課題を解決する。

---

## グラフの仕様

- **粒度**: シリーズ横断グラフ（同シリーズ全冊のキャラ・関係を 1 グラフに統合）
- **フィルタ**: 冊単位で表示範囲を絞り込み可能
- **同名キャラ**: 冊単位で別ノードを許容（第 1 巻の潤月 ≠ 第 5 巻の潤月）

---

## 関係データの抽出

| 手法 | 用途 | 実装 |
|---|---|---|
| 共起情報 | エッジの重み（線の太さ） | 同チャンク内の共出現回数をカウント |
| Qwen 抽出 | エッジラベル（関係タイプ） | character_summary テキストから JSON で抽出（友人・敵対・師弟 等） |

両手法を組み合わせる。共起はエッジの「強さ」、Qwen は「質」を担う。

---

## データモデル（新テーブル）

`novel_db.sqlite` に追加:

```sql
CREATE TABLE character_relations (
    id            INTEGER PRIMARY KEY,
    series_id     TEXT    NOT NULL,
    book_id       INTEGER NOT NULL,
    char_a        TEXT    NOT NULL,
    char_b        TEXT    NOT NULL,
    relation_type TEXT,           -- Qwen 抽出ラベル（NULL = 共起のみ）
    weight        REAL    NOT NULL DEFAULT 1.0,  -- 共起回数由来
    generated_at  TEXT    NOT NULL
);
```

---

## 生成タイミング

Full Build に `generate_relations` モードを追加。B-23 の `generate_contexts` モードと同構造。
管理画面（`/novel/manage`）から単独実行も可能にする。

---

## UI

- **専用ページ**: `/novel/graph`
- **ナビゲーション**: サイドバーの novel セクションから遷移
- **操作フロー**: シリーズ選択 → vis-network でグラフ描画（ドラッグ・ズーム標準搭載）
- **冊フィルタ**: チェックボックスで表示する冊を選択
- **インタラクション**: ノードホバーでキャラ名表示、クリックでキャラ辞典サマリをサイドパネルに表示

### ライブラリ

`vis-network`（npm: `vis-network`）。  
少ないコードでインタラクティブなネットワーク図が完成し、カスタマイズ性も十分。

---

## スコープ外（やらないこと）

- 関係の手動編集・正誤訂正
- グラフの PNG / SVG エクスポート
- 複数シリーズの同時表示

---

## 失敗時の挙動

- Qwen 抽出が特定冊で失敗した場合: その冊をスキップ、成功冊のグラフを表示 + ログ警告
- 共起データが存在しない冊: ノードとして表示するがエッジなし

---

## 完了条件

1. Full Build で `character_relations` が自動生成される（`generate_relations` モード）
2. `/novel/graph` でシリーズ選択 → インタラクティブなグラフが描画される
3. 冊フィルタが機能する
4. pytest（関係抽出 service + API エンドポイント）/ vitest（グラフコンポーネント）のテストが通る
