# QuestionSection 左右レイアウト改修 要件

## 背景・目的

`QuestionSection`（1問1答）の履歴が縦長になり、ページ全体が見づらくなっている。
`ChatSection` と同様の左右2ペイン構成に変更することで、履歴を選択しながら内容を確認できるようにする。

## 変更後レイアウト

```
[質問入力欄]                    [送信]   ← 現状維持（上部帯）
[ストリーミング表示]                      ← 現状維持（入力欄直下）
─────────────────────────────────────────
左パネル(260px)        │ 右パネル(flex-1)
─────────────────── │ ─────────────────
[> Q: ABC…]          │ Q: ABC の全文
   全件               │ 2026-05-14 · 応答 12s
[   Q: DEF…]         │
   単冊: ○○           │ A: ～～～
                      │
                      │ 参照: 本A p12  本B p34
```

## 仕様詳細

### 左パネル

| 項目 | 仕様 |
|------|------|
| 各行1行目 | 質問文（truncate、折り返しなし） |
| 各行2行目 | スコープ（全件 / シリーズ: ○○ / 単冊: ○○）小さいフォント |
| 選択状態 | ハイライト（ChatSection と同じスタイル） |
| 削除ボタン | ホバー時に右端に Trash アイコン表示、ConfirmDialog あり |
| 高さ制限 | `max-h-[600px]`、スクロール可 |

### 右パネル

| 項目 | 仕様 |
|------|------|
| 未選択時 | プレースホルダー文言を表示 |
| 選択時・質問 | 質問全文 |
| 選択時・メタ情報 | 日時（JST）・応答時間 |
| 選択時・回答 | 回答テキスト（whitespace-pre-wrap） |
| 選択時・参照 | 参照ページボタン群（クリックで画像モーダルへ） |
| 詳細取得 | 選択時にオンデマンド fetch（現行の `fetchQaHistoryDetail` を維持） |

### 送信完了後の動作

- SSE 完了 → 履歴 refetch → 新エントリを自動選択して右パネルに表示

### ストリーミング表示

- 現状維持：入力欄直下に `QuestionStreaming` コンポーネントを表示

## 影響ファイル

| ファイル | 変更内容 |
|---------|---------|
| `frontend/src/components/novel_db/QuestionSection.tsx` | 上部入力帯 + 下部左右グリッドのレイアウトに変更。選択状態管理を追加 |
| `frontend/src/components/novel_db/QuestionHistoryList.tsx` | 左パネル用リスト表示に変更 |
| `frontend/src/components/novel_db/QuestionHistoryItem.tsx` | 左パネル行コンポーネントに変更（折りたたみ廃止、削除はホバー表示へ） |
| `frontend/src/components/novel_db/QuestionHistoryDetail.tsx` | 新規作成。右パネル詳細表示コンポーネント |

## スコープ外

- バックエンド API 変更なし
- ページネーション実装なし（50件取得のまま）
