## データディレクトリ構造 (backend/data/)

```
data/
├── main/
│   ├── pdfs/            ← 生成済みPDF（非圧縮・保管用。ビューアには使用しない）
│   ├── pdfs_compressed/ ← 圧縮版PDF（ビューアが /pdfs マウントで配信する実体）
│   ├── thumbnails/      ← サムネイル
│   ├── images/          ← 元WebP画像
│   └── complete/        ← 処理済みZIP/フォルダ
├── kindle/
│   ├── pdfs/ / thumbnails/ / images/
├── kindle_novel/
│   ├── pdfs/ / thumbnails/ / images/
└── meta/                ← 書籍メタデータ（作者名）
    ├── generated/meta.json
    ├── kindle/meta.json
    └── novel/meta.json
```

**注意:** `/pdfs` 静的マウントは `PDF_COMPRESSED_DIR`（pdfs_compressed/）を指す。
`pdfs/` は再生成用の元ファイル保管場所であり、ビューアからは直接参照されない。

`source` パラメータ: `generated`(default) / `kindle` / `novel`
