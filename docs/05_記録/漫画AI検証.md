## 詳細所感

### T1（シーン描写）
期待以上に視覚理解はできている。単純な場面説明なら実用に近い。ただしセリフを含む解釈が必要な場面では OCR 誤読に引きずられて精度が落ちる。

### T2（パネルフロー）
コマ割りの認識は良好。右→左・上→下を指示文で伝えれば正しく追える。コマ境界の検出精度も高く、最も期待できる能力。

### T3（複数ページのストーリー）
OCR 精度の低さが連鎖して悪化する。さらに女性キャラクターを男性と誤認することで、ストーリーの主語・関係性がまるごと崩れてしまう。ページをまたいだ同一人物追跡自体は一応できているが、性別誤認が致命的。

### T4（日本語 OCR）
縦書きの方向認識は持っているが正答率 30% 程度。セリフを正確に読む用途には yomitoku が必要で、Gemma の OCR を代替にする選択肢はない。

### T5（キャラクター識別）
外見特徴（髪型・服装・体格）の描写精度は高い。書き分けが少ないキャラで混同するが、キャラデザインの問題も大きく過度に減点すべきではない。

### 技術的発見（重要）

qwen3-vl:8b は Ollama の `images` 配列に複数画像を渡すと **空文字列を返す**（エラーなし、サイレント）。  
**回避策**: PIL で複数ページを縦連結して 1 枚の PNG にしてから送る（実装済み: `combine_pages()`）。

| 送信方法 | 結果 |
|---|---|
| `images` 配列に 2 枚 | 空文字列（サイレント失敗） |
| `content` 配列の `image_url` 形式 | 400 Bad Request |
| PIL 縦連結 → 1 枚 PNG | 正常に回答 |

### T4 OCR 詳細

正解テキスト:
```
仕事相手に手を出すと後々面倒になるわよ
大丈夫よ
あたし人を見る目は確かだから
```

qwen3-vl:8b の回答:
```
（キャラA）「カァ…」
（キャラB）「大丈夫よ あなたは見る目は確かだから」   ← "あたし"→"あなたは" のみ誤り
（キャラC）「仕事相手に手を出すと後々面倒になるわよー」
（効果音）「すっ」
（キャラA）「おはようございます」
（キャラB）「美人さん…」
（キャラC）「何、食べもの…」
```

主要 3 行はほぼ正確に抽出。効果音・追加セリフも捕捉（Gemma は主要セリフも誤読多数）。
