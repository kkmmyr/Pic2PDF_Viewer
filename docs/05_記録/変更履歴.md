## 2026-04-28: feat(reader,library) — 一括操作後の自動選択解除 + シリーズ「次の巻へ」ボタン

### 概要

ユーザー要望を 2 件反映:

1. **一括操作の成功時に選択モードを自動解除**: これまで作者・タグ・シリーズ・非表示・結合・サムネイル再生成の各バルク操作後も選択モードが続いていたが、成功時はチェックボックスを消して通常表示に戻すようにした。失敗時は選択を保持してリトライできる。
2. **シリーズ「次の巻へ」ボタン**: シリーズに属する書籍の最終ページに到達したとき、画面下部に **「次の巻へ →」紫色のフローティングボタン** を表示。クリックで同 `series_id` の `series_index` が次に大きい書籍を開いて 1 ページ目から表示し、閲覧記録も加算。次巻が存在しない場合・別フォルダにしかない場合はボタンは出ない。

### 実装

**①選択解除**
- `useLibraryManagement` に `clearSelection()` を追加（`setIsSelectionMode(false)` + `setSelectedItems(new Set())`）。
- `LibraryContext` に `onClearSelection` を公開。
- `LibraryPanel` の `handleBulkApplyAuthors` / `handleBulkApplyTags` / `handleBulkAssignSeries` / `handleBulkToggleHidden` / `handleMergePdfs` / `handleRegenThumbnailBulk` の成功パス末尾で呼ぶ。`handleMoveItems` は元から同等処理。

**②次の巻へボタン**
- `ViewerPage` から `ReaderPanel` に `onSelectPdf={onPdfClick}` を渡す。
- `ReaderPanel` で `useBookMeta(currentSource)` を使って現在書籍の `series_id` / `series_index` を取得し、同フォルダ・同シリーズで次に大きい index の書籍を `meta` から線形探索。
- 最終ページ/最終スプレッド到達（`isSpread ? pageNumber+1 >= numPages : pageNumber >= numPages`）かつ次巻ありかつ `onSelectPdf` 提供時のみ `<button>` を表示。
- クリックで `recordView` を呼んでから `onSelectPdf(nextName)`。`selectedPdf` 変化で `ReaderPanel` の useEffect が `resetPage()` するため次巻は 1 ページ目から開始。

### テスト

`frontend vitest`: 53 PASS（型チェックも通過）。バックエンドへの変更なし。動作確認は手動推奨（DnD と同じく UI インタラクション）。

## 2026-04-28: fix(ui) — グループ化 select の <option> 可読性問題を select 背景の中立化で解消

### 概要

直前の修正（`html.dark select option { background: gray-800 }`）も、Chromium 系ブラウザでは効かなかった。Chrome の最近の仕様では `<option>` の背景色を CSS で個別に上書きすることができず、`<select>` 自身の背景色が継承される。

### 修正

- `LibraryHeader.tsx` の「グループ化」select の背景クラスを `bg-white dark:bg-gray-800` に固定。
- 紫強調は `border-purple-400` + `text-purple-700` + `ring-1 ring-purple-200`（dark 系も同様）で表現。
- `index.css` の `select option { background-color: ... }` 上書きはフォールバックとして残す（他ブラウザや将来の挙動変化対応）。

### 主な変更ファイル

- `frontend/src/components/reader/LibraryHeader.tsx`

## 2026-04-28: fix(ui) — <option> 背景色を明示してダークモードの可読性を改善

### 概要

前回 `color-scheme: dark` を `<html>` に当てたが、`<select>` 自身に Tailwind の `bg-purple-50 dark:bg-purple-900/30` 等の背景色クラスが当たっていると、Chromium 系ブラウザではドロップダウンメニュー (`<option>`) の背景色がライトモードの薄ピンクのまま、文字色だけ `color-scheme: dark` の影響で白くなってしまい、結果として「薄ピンク背景 + 白文字」で読めない状況が発生していた。

### 修正

`index.css` で `<option>` の背景色と文字色を明示的に上書き：

```css
html.dark select option       { background: rgb(31,41,55); color: rgb(243,244,246); }
html:not(.dark) select option { background: rgb(255,255,255); color: rgb(17,24,39); }
```

これで Tailwind 側の `<select>` の背景色クラスが何であっても、ドロップダウンメニューは統一されたダーク/ライト UI で描画される。

### 主な変更ファイル

- `frontend/src/index.css`

## 2026-04-28: feat(library) — フィルターを URL に同期しブラウザ戻るボタンで解除可能に

### 概要

シリーズ / 作者カードのドリルダウン後にブラウザの戻るボタンで元の一覧に戻れなかった問題を解消。`authorFilter` / `seriesFilter` / `tagFilter` を URL クエリパラメータに同期し、フィルター変更が `pushState` されるように変更。

### 仕様

- `?author=` / `?series=` / `?tag=` の 3 つを URL に同期
- 値変更 → `useSearchParams.setSearchParams` → react-router-dom が `pushState`
- 戻るボタン → URL が前の状態へ → `useSearchParams` から派生する各フィルター値が変わる → グリッド再描画
- フォルダ移動・ソース切替・PDF 選択時は `useUrlState` の navigate メソッドが `setSearchParams({ path, source, ... })` で **全置換** するため、フィルターは自動クリア（既存挙動と整合）
- `searchText` は入力ごとに pushState されると履歴汚染するため、URL 同期しない

### 主な変更ファイル

- `frontend/src/components/viewer/LibraryPanel.tsx`
    - `useState` の `authorFilter` / `seriesFilter` / `tagFilter` を `useSearchParams` 派生に変更
    - 共通の `updateUrlFilter(key, value)` を経由して setter を構築
    - パス・ソース変更時の useEffect リセットは `searchText` のみに簡素化
- `docs/03_詳細設計/詳細設計書.md` — `useUrlState` の節に URL 同期されるフィルターを追記

### 検証

- frontend vitest: 53 件パス（既存維持）
- TypeScript 型エラーなし

## 2026-04-28: fix(useBookMeta) — allAuthors の undefined 混入で option key が衝突する警告を解消

### 概要

### 修正

`flatMap(e => e.authors ?? [])` でガード。

## 2026-04-28: fix(ui) — ドロップダウン (select/option) のダークモード対応

### 概要

`<select>` のドロップダウンメニュー（option 要素）は Tailwind の `dark:` 修飾子では制御できないネイティブ UI。ダークモードでも明るい背景・黒文字のままで読みづらかった。

### 修正

```css
html.dark      { color-scheme: dark; }
html:not(.dark){ color-scheme: light; }
```

`color-scheme` プロパティは Chromium / Firefox 共にネイティブフォーム要素のテーマを切り替える。これでドロップダウン展開時のメニューもダーク UI になる。
