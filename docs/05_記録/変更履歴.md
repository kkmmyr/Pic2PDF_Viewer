## 追加ガイド

新規エントリは本ファイル下部「直近の追記」セクションの**先頭**（最新が上）に `## YYYY-MM-DD: type — タイトル` 形式で追記する。`type` は `feat` / `fix` / `refactor` / `chore` / `docs` / `test` / `perf` / `style` / `revert` / `change` のいずれか。詳細フォーマットは `/changelog` スラッシュコマンドが直近コミットから草稿を生成する。

週境界（毎週月曜日）を跨いだら、本ファイル下部の前週分を切り出して `変更履歴/YYYY-Www.md` を新規作成し、上記「アーカイブ索引」テーブルに 1 行追加する。
