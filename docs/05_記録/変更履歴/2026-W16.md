## 2026-04-16: PDF検索機能修正・URLソース同期・コードリファクタリング

### 概要
PDF内テキスト検索が機能しなかった問題を修正。複数の根本原因を特定・解消。

### バグ修正

#### 1. novel ソースで画像モードに落ちていた問題
- `hooks/useBookImages.ts`: `source === 'novel'` の場合は画像取得をスキップし、PDF モードを強制。
  - `kindle_novel/images/` に PNG ファイルが存在するため従来は画像モードで開かれており、`<Document>` がレンダリングされず `onDocumentLoadSuccess` が呼ばれなかった。

#### 2. pdfjs Worker が正常に起動しない問題
- `components/viewer/ReaderPanel.tsx`: `workerSrc` を `new URL('pdfjs-dist/build/pdf.worker.min.mjs', import.meta.url).toString()` に変更。
  - `<Document>` コンポーネントと同一ファイル内で設定しなければならない（react-pdf の要件）。
  - Vite がビルド時にワーカーファイルを自動バンドルするため CDN 不要。
- `pages/ViewerPage.tsx`: 重複していた `workerSrc` 設定を削除。

#### 3. TextLayer スタイルが適用されない問題
- `components/viewer/ReaderPanel.tsx`: `import 'react-pdf/dist/Page/TextLayer.css'` を追加。ハイライト表示に必須。

#### 4. 検索バーを開いても表示されない問題
- `components/viewer/ReaderPanel.tsx`:
  - 検索バー表示条件を `isSearchOpen && showHeader` → `isSearchOpen` のみに変更。
  - `ReaderHeader` の `showHeader` を `showHeader || isSearchOpen` に変更（検索中はヘッダーを常に表示）。

#### 5. `pdfRef.current` が null になる タイミング問題
- `components/viewer/ReaderPanel.tsx`:
  - `searchAllPages(text, pdf)` の引数を `pdfRef.current` ではなく `PDFDocumentProxy` を直接受け取る形に変更。
  - `onDocumentLoadSuccess`: PDF ロード完了時点で `searchText` が入力済みなら即座に `searchAllPages` を呼び出す。

#### 6. ソース切り替え後に PDF URL が 404 になる問題
- `hooks/useUrlState.ts`: `currentSource` を URL `?source=` パラメータから取得・管理するよう変更。
  - 全ナビゲーション関数 (`navigateIntoFolder`, `navigateUp`, `selectPdf`, `clearPdf`) のシグネチャに `source: LibrarySource` を追加。
  - `resetAll()` を `setSource(source)` に置き換え（`?source=` のみ変更し他はリセット）。
- `pages/ViewerPage.tsx`: `currentSource` の `useState` を削除。`useUrlState()` から取得するよう変更。

### コードリファクタリング
- `backend/services/pdf_service.py`: `typing.List` → `list[int]`、`temp_path` の `finally` ブロッククリーンアップ。
- `backend/routers/library.py`: 未使用 `import fitz` / `List` 削除、`logger` 一元化。
- `frontend/src/hooks/useBookMeta.ts`: `updateAuthors` の `makeKey` 重複ロジックを共通関数に統一。

## 2026-04-14: 見開きモード3段階制御・書籍メタデータ（作者名）機能追加

### 概要
リーダーの見開き表示制御を拡充し（Auto/Spread/Single の3状態）、書籍単位の作者名管理機能を新設。

### 新機能

#### 1. 見開きモード3段階制御 (SpreadMode)
- `types/index.ts`: `SpreadMode = 'auto' | 'spread' | 'single'` 型を追加。
- `ReaderPanel.tsx`:
    - `spreadMode` + `autoIsSpread` の2状態で制御。実効値 `isSpread` を導出。
    - `cycleSpreadMode()`: Auto → Spread → Single → Auto の順に循環。
    - `handlePageSize(width, height)`: Auto モード時、縦長なら見開き・横長なら1ページに自動切り替え。
    - PDF切り替え時に `autoIsSpread` を `true` にリセット。
- `ReaderHeader.tsx`:
    - 従来の2状態トグルを3状態ボタンに変更（`SPREAD_MODE_CONFIG` 定数でラベル・アイコン・遷移先を管理）。
    - Auto モードは indigo 色で強調表示。
- `PageRenderer.tsx`:
    - `onPageSize?: (width, height) => void` コールバックを追加。
    - PDF: `<Page onRenderSuccess>` / 画像: `<img onLoad>` でページサイズを親に通知。
    - 右ページ/シングルページにのみ渡し、見開き時の二重発火を防止。

#### 2. 書籍メタデータ管理（作者名）
- `backend/routers/meta.py` 新規追加:
    - `GET /api/meta?source=` — meta.json 全体を返す。
    - `PATCH /api/meta` — 複数書籍への作者名一括上書き。ソース別 `threading.Lock` でスレッドセーフ。
    - データ: `backend/data/meta/{source}/meta.json`（キー: `"{path}/{filename}"` or `"{filename}"`）
- `hooks/useBookMeta.ts` 新規追加:
    - source 変更時に自動フェッチ。ローカル即時反映（再フェッチ不要）。
    - `allAuthors`: 全作者名の重複排除・日本語ソート済みリスト（フィルター用）。
- `components/viewer/BulkAuthorDialog.tsx` 新規追加:
    - タグ形式入力（Enter/カンマで確定、Backspace で削除）。
    - 複数書籍を選択して「作者を設定」から呼び出す。上書き方式。
- `LibraryPanel.tsx`: 検索ロジックを拡張。タイトルまたは作者名に部分一致する書籍を絞り込む。
- `LibraryHeader.tsx`: 作者フィルタードロップダウンを追加。全作者をリストアップし、選択中の作者で完全一致フィルター。
- `PdfGrid.tsx`: 書籍カードに作者名タグを表示。
- カード直クリックでPDFリーダーに遷移（BookDetailPanel を削除）。単冊の作者名編集は選択モード（1冊選択）から実施。

## 2026-04-14: 新機能追加 & MUI→Tailwind統一

### 概要
UX改善機能を4点実装し、フロントエンドのUIライブラリをMUI→TailwindCSS（Tailwind統一）に移行。

### 新機能

#### 1. PDF生成の非同期化 (Backend + Frontend)
- `backend/routers/pdfs.py`: `JobStore` / `GenerateJob` クラスを新設。UUIDジョブ管理 + スレッドセーフ設計。
- `POST /api/generate` → バックグラウンドスレッドで実行、`job_id` を即返却。
- `GET /api/generate/job/{job_id}` → ジョブ進捗ポーリングエンドポイントを追加。
- フロントエンド (`GeneratorPage.tsx`): 1500msポーリング、進捗UI（Clock/CheckCircle/XCircle アイコン、プログレスバー）。

#### 2. お気に入り / 並び替え
- `useFavorites.ts`: ソース別 `localStorage` 永続化。ソース切り替え時に自動再ロード。
- `useSortedPdfs.ts`: 5種類のソート順に対応 (`name_asc/desc`, `date_asc/desc`, `favorites_first`)。
- `LibraryPanel.tsx` / `LibraryHeader.tsx`: ソート順セレクタ追加 + localStorage永続化。
- `PdfGrid.tsx`: サムネイル左上に★ボタン追加。お気に入り状態をアンバー色で表示。
- `library.py`: `/api/pdfs` レスポンスに `created_at` (Unix timestamp) を追加。

#### 3. ダークモード
- `tailwind.config.js`: `darkMode: 'class'` 設定。
- `index.html`: React マウント前にインラインスクリプトで `<html class="dark">` 適用（フラッシュ防止）。
- `useDarkMode.ts`: `useState` 初期化時に即適用 + `localStorage` 永続化 + システムカラースキームフォールバック。
- 全コンポーネントに `dark:` クラスを適用。`Layout.tsx` にMoon/Sunトグルボタン追加。

#### 4. サムネイル遅延読み込み (Lazy Load)
- `LazyThumbnail.tsx`: `IntersectionObserver` (rootMargin 200px) でビューポート外のサムネイルを遅延読み込み。エラー時はFileTextアイコンにフォールバック。

#### 5. PDF内テキスト検索
- `PdfSearchBar.tsx`: Ctrl+F でサーチバーを開く。300msデバウンス入力、Enter/Shift+Enterで次/前移動、マッチ数表示。
- `ReaderPanel.tsx`: pdfjs で全ページテキストを走査してマッチカウント、`customTextRenderer` でハイライト表示。`renderTextLayer` は検索中のみ有効化（パフォーマンス最適化）。

### MUI→TailwindCSS統一
- `OCRPanel.tsx` / `OCRPage.tsx`: MUI `Box` / `Typography` / `Button` / `Chip` → Tailwindクラスに完全置き換え。`ThemeProvider` を削除。
- `CreateFolderDialog.tsx`: MUI `Dialog` → Tailwind固定オーバーレイ実装。バリデーション・Escクローズ・Enterサブミット・外クリックで閉じる。
- `package.json`: `@mui/material`, `@mui/icons-material`, `@emotion/react`, `@emotion/styled` を削除（約123パッケージ削減）。
