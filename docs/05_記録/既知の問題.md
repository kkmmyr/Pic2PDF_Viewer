# 既知の問題

---

## SearXNG 上流エンジンのレート制限によるサークル名自動登録失敗

### 概要

サークル名自動登録機能を大量（目安: 20件以上）実行すると、SearXNG の上流検索エンジンが
レート制限・CAPTCHA ブロックを受け、全件「作者不明」が返るようになる。

### 症状

- `GET /api/meta/auto-fill/test` の `searxng_hit` が `false` を返す
- `unresponsive_engines` に以下のようなメッセージが並ぶ:

```json
"unresponsive_engines": [
  ["brave",      "一時停止: リクエストが多すぎます"],
  ["duckduckgo", "CAPTCHA"],
  ["karmasearch","一時停止: アクセスが拒否されました"],
  ["startpage",  "解析エラー"]
]
```

SearXNG の確認 URL: `http://localhost:8080/search?q=test&format=json`

### 根本原因

SearXNG は複数の外部検索エンジンに並列リクエストを送る。短時間に大量リクエストを行うと
各エンジン側でボットとみなされ、一時停止・CAPTCHA・アクセス拒否が発生する。

### 対処方法

#### 1. 制限解除を待つ（数時間〜1日）

ブロックは時間経過で解除される。解除後に「作者不明」のエントリは自動的に再試行対象となる
（`overwrite=false` でも「作者不明」エントリは再処理される設計）。

#### 2. 待機時間の設定

`backend/routers/meta.py` の待機時間（現在 5 秒）を調整する。  
件数が多い場合はさらに延ばすことを検討する。

```python
time.sleep(5.0)  # 必要に応じて 10〜30 秒に延ばす
```

#### 3. 分割実行

一度に全件処理せず、数十件ずつ日を分けて実行する。

### 将来の改善案

汎用検索エンジンの代わりに **DLsite を直接クエリする方式** への移行を検討中。
DLsite は同人誌専門の DB であり、サークル名・著者名の精度・安定性が大幅に向上する見込み。
