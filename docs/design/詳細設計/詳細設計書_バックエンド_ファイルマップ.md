## 2. 主要ファイル補足

§1 のツリーだけでは分からない、非自明な役割・落とし穴を持つファイルのみを選んで補足する。ファイル名から役割が読み取れるものは掲載しない。

| パス | 補足 |
|---|---|
| [backend/routers/_deps.py](../../../backend/routers/_deps.py) | ルーター共通の FastAPI 依存ヘルパー集約（source 検証・パス検証・例外→500 変換・SSE イベント整形など）。`_` 接頭辞だが大半のルーターが利用する横断インフラ |
| [backend/routers/pdfs.py](../../../backend/routers/pdfs.py) | ページ削除・PDF 結合のみ。PDF 生成系は同じ「PDF 系」でも `generate.py` に分離されている |
| [backend/routers/novel_build.py](../../../backend/routers/novel_build.py) | `novel_db` の `job_queue` シングルトンを薄くラップし、`mode=full_build` 専用の enqueue/status/cancel/SSE を提供する別ルーター（ジョブストアは novel_db 本体と共有） |
| [backend/routers/novel_db/lib.py](../../../backend/routers/novel_db/lib.py) | 書籍/シリーズ/作者一覧・詳細・メタインポート API。ファイル名の「lib」はユーティリティの意味ではなく「library」の略 |
| [backend/routers/hitomi.py](../../../backend/routers/hitomi.py) | 薄いラッパーのみ。実処理は `services/hitomi/*` にある |
| [backend/services/series_detector.py](../../../backend/services/series_detector.py) | シリーズ手動割当 API 用の純関数（`authors_key` / `stable_series_id`）。自動グループ化ロジックではない |
| [backend/services/series_suggester.py](../../../backend/services/series_suggester.py) | 既存シリーズへの紐付けをルールベースで提案する読み取り専用関数群。`series_detector.py` と名前が似ているが役割は別（新規シリーズの自動検出はしない） |
| [backend/services/amazon_csv_parser.py](../../../backend/services/amazon_csv_parser.py) | CSV 行レベルのパースのみを担う純関数群 |
| [backend/services/amazon_csv_importer.py](../../../backend/services/amazon_csv_importer.py) | インポート全体のオーケストレーション（lookup 構築・タイトル正規化マッチング・meta.json 補完）。`amazon_csv_parser.py` は内部で使う部品 |
| [backend/services/kindle_catalog/](../../../backend/services/kindle_catalog/) | Linux 正本の Kindle 購入カタログ。専用 Alembic DB、旧DB移行、Amazon CSV 差分取込、Pic2PDF既存画像の手動ASIN紐付け、capture job/inbox検証を分離して持つ |
| [kindle-pdf/capture_agent.py](../../../kindle-pdf/capture_agent.py) | Windows で Linux の capture job を claim し、既存 capturer の画像を専用 Samba inbox へ `.partial` → `.ready` で送る。購入カタログや正式画像領域は保持しない |
| [backend/services/image_service.py](../../../backend/services/image_service.py) | `doujin`（画像のみモード）専用のページ操作。`PdfService` の画像版に相当するが、ファイル名に「doujin」は出てこない |
| [backend/services/meta_db.py](../../../backend/services/meta_db.py) | SQLite 接続初期化・テーブル定義・起動時の JSON → DB 自動移行を担う（`init_db()` を `main.py` から呼び出す） |
| [backend/services/_title_normalizer.py](../../../backend/services/_title_normalizer.py) | `amazon_csv_importer.py` 専用の private ヘルパー。単体では他から呼ばれない |
| [backend/services/meta_db_backup.py](../../../backend/services/meta_db_backup.py) | `sqlite3.backup()` によるホットバックアップ。バックアップ先は OneDrive 同期フォルダを想定した外部ディレクトリ（`META_DB_BACKUP_DIR`）で、リポジトリ内には作られない |
| [backend/services/novel_db/_llm_backend.py](../../../backend/services/novel_db/_llm_backend.py) | Qwen/Gemma LLM バックエンドのシングルトン管理。設定値ではなく、接続を使い回すオブジェクトの実体 |
| [backend/services/novel_db/page_fts.py](../../../backend/services/novel_db/page_fts.py) | SQLite `pages`を正本にしたpage-level LanceDB ICU BM25。世代別完全再構築、公開前整合検査、active pointer検証、stale管理、検索時のFTS5縮退境界を持つ |
| [backend/scripts/build_page_fts_index.py](../../../backend/scripts/build_page_fts_index.py) | page-level ICU索引を手動構築する運用CLI。Alembicをheadへ上げ、本文を含まないJSON manifestをstdoutへ1件だけ出力する |
| [backend/services/novel_db/graph_query.py](../../../backend/services/novel_db/graph_query.py) | `character_relations` の読み取り専用クエリ層。書き込みは `relation_extractor.py` が担い、`novel_graph` ルーターはこちらからのみ読む |
| [backend/utils/dt.py](../../../backend/utils/dt.py) | JST タイムゾーン定数 `JST` と `jst_now()`。DB のタイムスタンプは `datetime.now()` ではなくこちらで統一する |
| [backend/utils/locks.py](../../../backend/utils/locks.py) | `SourceLockManager`。`meta_store` / `genre_store` / `prefs_store` はそれぞれ別インスタンスを持ち、ロックは共有されない |
| [backend/config/__init__.py](../../../backend/config/__init__.py) | `from .novel_db import *` で再エクスポートするため、呼び出し側は `from config import NOVEL_DB_XXX` のように分割を意識せず import できる |
| [backend/services/hitomi/nozomi.py](../../../backend/services/hitomi/nozomi.py) | 「NOZOMI」は hitomi.la 側のバイナリ形式ギャラリー ID リストの名称（内部コードネームではない） |
| [kindle-pdf/run_comic.bat](../../../kindle-pdf/run_comic.bat) | `uv run` ではなく `.venv\Scripts\python.exe` を直接呼ぶランチャー（`run_novel.bat` も同様） |
