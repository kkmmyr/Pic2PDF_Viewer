## 2. 主要ファイル補足

§1 のツリーだけでは分からない、非自明な役割・落とし穴を持つファイルのみを選んで補足する。ファイル名から役割が読み取れるものは掲載しない。

| パス | 補足 |
|---|---|
| [router.tsx](../../../frontend/src/router.tsx) | 各ルートに `errorElement: <RouteErrorPage />` を設定。Layout 内の `ErrorBoundary`（実行時レンダリングエラー用）とは対象が異なり、両方が併存する |
| [components/ErrorBoundary.tsx](../../../frontend/src/components/ErrorBoundary.tsx) | `Layout.tsx` が `<Outlet>` を囲むために使う実行時エラーバウンダリ。ルート読み込みエラーは `RouteErrorPage.tsx` が別途担当する（重複ではない） |
| [components/GlobalNavigation.tsx](../../../frontend/src/components/GlobalNavigation.tsx) | PCのカテゴリ別ドロップダウン、モバイルのナビゲーションドロワー、URLから導出するカテゴリ名・画面名を一元管理する。Kindle領域内の詳細導線は`KindlePageShell.tsx`のサブナビゲーションが担当する |
| [components/global-navigation-config.ts](../../../frontend/src/components/global-navigation-config.ts) | グローバルナビゲーションのカテゴリ・リンク・ルート別現在地と共通classを保持し、描画・開閉ロジックから静的定義を分離する |
| [components/RouteErrorPage.tsx](../../../frontend/src/components/RouteErrorPage.tsx) | router の `errorElement`。`ErrorBoundary.tsx` とは別レイヤーで併存する |
| [components/ui/confirm-dialog.tsx](../../../frontend/src/components/ui/confirm-dialog.tsx) | `ui/` 内では珍しい kebab-case ファイル名（`searchable-select.tsx` / `tags-input.tsx` も同様の命名規約） |
| [components/ui/searchable-select.tsx](../../../frontend/src/components/ui/searchable-select.tsx) | 同上の命名規約。`BulkSeriesAssignDialog` / `BulkAuthorDialog` から使用 |
| [components/ui/tags-input.tsx](../../../frontend/src/components/ui/tags-input.tsx) | 同上の命名規約。命名は歴史的経緯（タグ機能撤去後も chip 入力 UI として残置） |
| [components/novel_db/NovelDbHeader.tsx](../../../frontend/src/components/novel_db/NovelDbHeader.tsx) | 現行画面では未使用。`novel_db/index.ts` の barrel export のみに残る |
| [components/novel_db/ScopeSelector.tsx](../../../frontend/src/components/novel_db/ScopeSelector.tsx) | 同上、`NovelDbHeader.tsx` からのみ参照される未使用ファイル |
| [hooks/reader/useReaderUIState.ts](../../../frontend/src/hooks/reader/useReaderUIState.ts) | ヘッダー/スライダー/検索/ヘルプの表示トグルを集約。`toggleBothUI` は中央タップで両方同時に表示⇄非表示、`pauseSliderTimer`/`resumeSliderTimer` はドラッグ中に両方のタイマーを一時停止する |
| [hooks/reader/useTouchSwipe.ts](../../../frontend/src/hooks/reader/useTouchSwipe.ts) | スワイプの検知のみを担い、LTR/RTL の意味づけは行わない（呼び出し側の `ReaderPanel` が方向を解釈する） |
| [components/reader/ReaderPanel.tsx](../../../frontend/src/components/reader/ReaderPanel.tsx) | `direction` により左右スワイプの意味が反転する（LTR: 左送りで次ページ／RTL: 右送りで次ページ）。関連書籍ページ表示中はヘッダー/スライダーが常時表示になる |
| [components/reader/RelatedBooksPage.tsx](../../../frontend/src/components/reader/RelatedBooksPage.tsx) | 実ページではなく、最終ページの次に来る仮想ページとして描画される |
| [hooks/library/useBookMeta.ts](../../../frontend/src/hooks/library/useBookMeta.ts) | 実装本体ではなく、責務別 4 フック（`useBookMetaCore`/`useBookMetaWrite`/`useBookSeries`/`useBookView`）+ `useMetaDerived` をまとめる薄いファサード |
| [hooks/library/useLibraryPins.ts](../../../frontend/src/hooks/library/useLibraryPins.ts) | 初回ロード時に localStorage → `meta2.db`（`/api/prefs`）への一回限りの自動移行を行う（`useLibrarySettings.ts` も同様の移行を持つ） |
| [contexts/LibraryPanelContext.tsx](../../../frontend/src/contexts/LibraryPanelContext.tsx) | `LibraryHeader` / `LibraryDialogs` / `GenreFilterBar` / `SeriesEditDialog` は props を受け取らず、ここから context 経由で状態を取得する |
| [contexts/ReaderContext.tsx](../../../frontend/src/contexts/ReaderContext.tsx) | 同様のパターン。`ReaderHeader` / `ReaderPageView` / `ShortcutsHelpDialog` が props なしで消費する |
| [config/generate_api_client.ts](../../../frontend/src/config/generate_api_client.ts) | PDF 生成専用の別 axios インスタンス（タイムアウト延長）。通常の `api_client.ts` とは別物で使い分けが必要 |
| [lib/queryClient.ts](../../../frontend/src/lib/queryClient.ts) | 既定値は `staleTime: 0`。`meta` / `genres` 系クエリは各フック側で `staleTime: Infinity` を個別指定して楽観的更新を維持している |
| [types/api.d.ts](../../../frontend/src/types/api.d.ts) | OpenAPI からの自動生成ファイル（4700 行超）。直接編集せず `npm run generate:types` で再生成する |
| [hooks/novel_db/useNovelDbBooks.ts](../../../frontend/src/hooks/novel_db/useNovelDbBooks.ts) | 全ページで React Query キャッシュ `['novelBooks']` を共有する。ページごとの個別 fetch ではない |
| [hooks/useCurrentSource.ts](../../../frontend/src/hooks/useCurrentSource.ts) | 現在の source（doujin/comic/novel）は state や store ではなく、毎回 URL パス（`useLocation().pathname`）から導出される |
| [pages/KindleCatalogPage.tsx](../../../frontend/src/pages/KindleCatalogPage.tsx) | URL 同期検索、25 / 50 / 100 件ページング、レスポンシブ表、書籍詳細ダイアログを持つ購入書籍ページ |
| [pages/KindleLinksPage.tsx](../../../frontend/src/pages/KindleLinksPage.tsx) | 未紐付け既存画像と Kindle 候補を比較し、最終確認後だけ ASIN を設定する |
| [pages/KindleCapturePage.tsx](../../../frontend/src/pages/KindleCapturePage.tsx) | capture job の active / failed / succeeded、工程、経過時間、撮影画面数、失敗別対処、確認付き再実行を表示する。新規撮影の初回作成は購入書籍詳細から行う |
| [pages/KindleImportsPage.tsx](../../../frontend/src/pages/KindleImportsPage.tsx) | 既存 3 API の順次・個別差分取込、取込履歴、低頻度の旧 DB 移行を担当する |
| [components/kindle/KindlePageShell.tsx](../../../frontend/src/components/kindle/KindlePageShell.tsx) | Kindle 4 ページの見出し、説明、固有 URL 付きサブナビゲーションを共通化する |
| [hooks/useKindleCatalog.ts](../../../frontend/src/hooks/useKindleCatalog.ts) | Kindle カタログの用途別 TanStack Query フックと mutation/invalidate を集約。候補取得は選択時だけ有効化する |
| [features/novel_graph/api.ts](../../../frontend/src/features/novel_graph/api.ts) | `novel_build/api.ts` / `novel_db/api.ts` と同様、モジュールごとに個別の `PREFIX` 定数（例: `/api/novel_graph`）を持つ。共通 axios baseURL の一部ではない |
