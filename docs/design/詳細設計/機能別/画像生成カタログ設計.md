# 画像生成カタログとの境界

> status: living | last-verified: 2026-09-05

`imagegen-catalog` はPic2PDF Viewerとは別リポジトリの独立アプリである。このリポジトリには、そのAPI・DB・画面の実装を持たない。

## 正本

別リポジトリ `D:\61.tool\imagegen-catalog` の `docs/design/README.md` を入口とし、個別設計は同リポジトリの `docs/design/`、稼働状態の観測記録は `docs/production-state.md` を参照する。この文書へ他アプリの設定値や稼働状態を複製しない。

## 旧文書の扱い

この場所にあったJSON中心の初期設計は[初期設計記録](../../../archive/検証/画像生成カタログ_初期設計_2026-08.md)へ分離した。現在の他リポジトリの実装・運用を保証する資料ではない。

Pic2PDF Viewerの設計照合では、独立アプリであることと正本の所在を確認する。画像生成カタログ自身のAPI・DB・稼働環境の検証は、そのプロジェクトで行う。
