## 現行の連携境界

- 書籍のsourceは `doujin` / `comic` / `novel`。Kindleキャプチャはworkspace内の `kindle-pdf/` とWindows agent、Linux受信処理まで本プロジェクトの責務に含む。単なる外部ツールの画像閲覧だけではない。
- hitomi監視は新着メタデータを取得する。実行頻度・取得契約は[hitomi新着監視設計書](../詳細設計/機能別/hitomi新着監視設計書.md)を参照する。
- 撤去済みのDLsite / FANZA自動補完を現在の連携機能として扱わない。
- ローカル推論と外部送信の境界は[セキュリティ設計書](../詳細設計/セキュリティ設計書.md)が正本。明示的なopt-inのSol/Codex経路があるため、アプリ全体を「外部送信なし」とは記載しない。
- 保存する画像・OCR本文・メタデータ・閲覧履歴・ログは、[運用ガイド](運用ガイド.md)の保管・バックアップ契約に従う。
