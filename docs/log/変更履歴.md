## 追加ガイド

新規エントリは本ファイル下部「直近の追記」セクションの**先頭**（最新が上）に `## YYYY-MM-DD: type — タイトル` 形式で追記する。`type` は `feat` / `fix` / `refactor` / `chore` / `docs` / `test` / `perf` / `style` / `revert` / `change` のいずれか。詳細フォーマットは `/changelog` スラッシュコマンドが直近コミットから草稿を生成する。

週境界（毎週月曜日）を跨いだら、本ファイル下部の前週分を切り出して `変更履歴/YYYY-Www.md` を新規作成し、上記「アーカイブ索引」テーブルに 1 行追加する。

## 直近の追記（2026-W29: 2026-07-13 〜）

## 2026-07-18: fix — CI frontend / backend / docs の3ジョブを復旧

GitHub Actions の3ジョブがそれぞれ独立した原因で失敗していたため、[CI修理計画書](計画/CI修理計画書.md) に沿って最小差分で修正した。

- **frontend**: ESLint 10 と `eslint-plugin-jsx-a11y` の peer 競合を ESLint 9 系への整合で解消し、TypeScript 6 と `openapi-typescript` の peer 要求は npm `overrides` で限定的に吸収。`npm ci`、lint、tsc、998 tests が成功。
- **backend**: 空のサマリテーブルで Ollama embedding を呼ぶ前に `[]` を返すよう処理順を修正。Ollama 到達不能条件を含む 893 tests、Ruff、basedpyright が成功。
- **docs**: 実行時生成物 `backend/.coverage` をファイルマップ生成対象から除外し、クリーン CI とローカル生成結果のドリフトを解消。docs 整合性チェック、ファイルマップ freshness、MkDocs strict build が成功。
