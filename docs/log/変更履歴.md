## 追加ガイド

新規エントリは本ファイル下部「直近の追記」セクションの**先頭**（最新が上）に `## YYYY-MM-DD: type — タイトル` 形式で追記する。`type` は `feat` / `fix` / `refactor` / `chore` / `docs` / `test` / `perf` / `style` / `revert` / `change` のいずれか。詳細フォーマットは `/changelog` スラッシュコマンドが直近コミットから草稿を生成する。

週境界（毎週月曜日）を跨いだら、本ファイル下部の前週分を切り出して `変更履歴/YYYY-Www.md` を新規作成し、上記「アーカイブ索引」テーブルに 1 行追加する。

## 直近の追記（2026-W29: 2026-07-13 〜）

## 2026-07-18: fix — CI frontend / backend / docs の3ジョブを復旧

GitHub Actions の3ジョブがそれぞれ独立した原因で失敗していたため、[CI修理計画書](計画/CI修理計画書.md) に沿って最小差分で修正した。

- **frontend**: ESLint 10 と `eslint-plugin-jsx-a11y` の peer 競合を ESLint 9 系への整合で解消し、TypeScript 6 と `openapi-typescript` の peer 要求は npm `overrides` で限定的に吸収。npm 10 で lockfile を再生成し、npm 10 / 11 双方の `npm ci`、lint、tsc、998 tests が成功。
- **backend**: 空のサマリテーブルで Ollama embedding を呼ぶ前に `[]` を返すよう処理順を修正。Ollama 到達不能条件を含む全テスト、Ruff、basedpyright が成功。
- **docs**: 実行時生成物 `backend/.coverage` とローカル専用ディレクトリ `backend/data/` / `backend/input/` をファイルマップ生成対象から除外し、クリーン CI とローカル生成結果のドリフトを解消。

## 2026-07-07: feat — B-28 読書会 番組台本生成（構成化台本 + 固定ホストキャラ、B-20 を置き換え）

「だらだら話すだけ」だった B-20 読書会を、固定ホストキャラ 2 人（レイ＆ミオ）による 10 分尺の番組台本生成に置き換えた。要件・DoD・UI/API 契約は [読書会ロングフォーム拡張_要件.md](../design/要件定義/読書会ロングフォーム拡張_要件.md)（§4.6〜4.11・§10）で事前確定済み。

- **バックエンド（2 段 LLM パイプライン）**: `discussion_cast.py`（人格核定数）/ `discussion_prompts.py`（構成・台本テンプレート + `SEGMENTS`/`SEGMENT_TURNS`）/ `discussion_checks.py`（機械チェック M1〜M5）を新設。①構成ステップ `generate_plan`（対立する推し解釈・テーマ 2 件・脱線ネタカード [facts/keywords 付き] を JSON 生成、temperature 0.4）→ ②台本ステップ（5 セグメント構成 + `[S:id]` 境界マーカー、temperature 0.7）。両呼び出しの system 先頭（書籍本文）を完全一致させ llama-server の KV cache で 2 段目の prompt processing をほぼゼロ化。
- **パーサ寛容化**: Phase 0b で観測したマーカードリフト（`[A]:`→`[A>:` 等）を許容する `_TURN_RE` に差し替え。セグメントマーカーはチャンク分断による ID 誤検出ガード付きで逐次検出。
