## 2026-07-04: feat — 同人誌フォルダ監視による自動取り込み（置くだけで取り込まれる）

- **背景**: 「入力フォルダに ZIP を置く → Generate ボタンを押す」というバッチ型 UX を、「置くだけで自動的に取り込まれる」常時同期型に変更。
- **方式**: watchdog（FS イベント）ではなく**ポーリング + 静穏検知**。入力元が Samba 共有（`DOUJIN_INPUT_DIR`）でありイベント通知が信頼できないため。`DoujinWatcher`（`backend/services/doujin_watcher.py`）が lifespan 常駐でデフォルト 15 秒間隔スキャン。スナップショット（ZIP: サイズ+mtime / フォルダ: ファイル数+合計サイズ+最大 mtime）が 2 回連続一致でコピー完了とみなしジョブ自動起動。
- **排他制御**: ジョブ実行ロジックを `services/generate_service.py` に分離し、手動 `POST /api/generate` と自動起動が同一コードパス + 共有 `asyncio.Lock` を通る。実行中の手動リクエストは 409。**従来の「手動連打で並行実行される」バグも解消**。
- **失敗残骸の再試行抑制**: 前回自動起動時とスナップショット同一なら自動再実行しない（`retry_blocked`）。手動「今すぐスキャン」でのみ再試行（成功時に抑制解除）。
- **API**: `GET /api/generate/watcher`（状態・検出中アイテム・実行中ジョブ）追加。`GenerateJob` に `trigger: manual|auto` 追加。設定 `DOUJIN_WATCH_ENABLED` / `DOUJIN_WATCH_INTERVAL_SEC` 追加。
- **フロントエンド**: GeneratorPage に監視状態カード（状態バッジ・最終スキャン・検出中アイテム・再試行ブロック警告）。Generate ボタンは「今すぐスキャン」に改称。自動起動ジョブも既存の進捗 UI で追跡。
- **設計書**: 要件定義書 §2.2 / 基本設計書 データフロー1 / 詳細設計書_バックエンド編（generate_service・DoujinWatcher 節追加）を更新。
