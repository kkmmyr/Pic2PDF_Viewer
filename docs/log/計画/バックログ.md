## B. 中優先

<a id="b-26"></a>
### B-26. 書籍類似度推薦（novel）

**価値**: 書籍詳細から次に読む類似本を探し、読書会の比較トークにも使う。

**現在地**: サマリembedding KNNによる簡易版B-19は実装済み。3軸合成版は未実装である。

**次の一手**: bge-m3全文、サマリ、タグ／著者の3軸を調整可能な重みで合成し、最大5件を表示する
評価案を固定する。
`book_similarities`へ事前計算し、管理画面から手動更新する。B-19のサマリembedding KNNは既存の簡易版。

**完了条件**: 評価集合で重み・閾値を決め、schema、API、UI、再計算運用を設計して実装する。
初期検討は[凍結要件メモ](../../archive/要件/書籍類似度推薦_初期要件メモ.md)を参照。

<a id="b-28"></a>
### B-28. 読書会ロングフォーム Phase 1 — 主観受入待ち

**現在地**: 機能と機械checkは実装済みで、利用者の主観受入だけが残る。現行契約は
[検索QA設計 §8](../../design/詳細設計/機能別/小説RAG_検索QA設計.md)を正本とする。

**残作業**: 層1合格台本1件を利用者が確認し、「笑える／へえ」が3箇所以上か、キャラがぶれないかを判定する。
合格なら本項目を削除し、不合格なら具体的な評価項目だけを別候補として起票する。

<a id="b-29"></a>
### B-29. 読書会 Phase 2 — 類似本トーク連携

**現在地**: B-28受入待ち。既存`find_similar_books`と`books.summary`は利用できる。

**次の一手 / 完了条件**: B-28受入後に両者を脱線ネタカードへ接続し、根拠付き類似本トークを
受入確認する。蔵書外の一般知識は事実根拠として扱わず、B-26は前提にしない。

<a id="b-30"></a>
### B-30. 読書会 Phase 3 — 時事・教養小話の密度強化

**現在地**: B-28受入待ちで未設計。

**次の一手 / 完了条件**: B-28の受入結果からステップ分離の要否を決め、脱線候補を複数生成して
選別する構成を評価する。固有情報を根拠付きネタカードへ固定し、受入台本で誤情報がないことを確認する。

### B-31. 重複作品検出（doujin）

**現在地**: 未実装。既存の同一書籍名・同一ジョブ判定は画像内容の近似重複を検出しない。

**次の一手 / 完了条件**: 既存ライブラリのbackfill、perceptual hashの対象ページ、閾値、確認UIを
先に確定し、取込時に近似候補を警告できれば完了とする。自動削除・取込拒否はしない。

### B-2. メタデータ一括インポート

**現在地**: Amazon固定形式CSVによる著者・ASIN補完は実装済み。任意のJSON / CSVから書誌メタ全体を
移行する汎用インポートは未実装である。

**次の一手 / 完了条件**: schemaと`upsert / overwrite / skip`を確定し、dry-run、rollback、衝突結果を
提示したうえで、既存エクスポートから別環境へ復元できれば完了とする。

### B-4. キーボードショートカットのカスタマイズ

**現在地**: readerの固定ショートカットは実装済み。利用者ごとのkey map編集は未実装である。

**次の一手 / 完了条件**: 衝突、予約キー、初期化、既存操作との互換を決め、action-key mapを
localStorageへ保存して設定画面から安全に編集・初期化できれば完了とする。

### B-17. 漫画画像キャプション検索 — 保留

**現在地**: パイロットでは`qwen3-vl:8b`がGemmaより良好だったが、実用品質には未達として停止中。

**再開条件 / 完了条件**: project ownerが新しいローカルVLM候補を指定したとき、1冊pilotで精度、処理時間、
複数画像の縦連結回避策、全冊規模を確認する。受入基準確定後にDB・API・UIを実装できれば完了とする。

### B-18. リーダー統合「ここまでのあらすじ」

**現在地**: 未実装。既存の書籍全体要約は任意ページのネタバレ境界を扱わない。

**次の一手 / 完了条件**: ネタバレ境界、再生成、OCR更新時の無効化を決め、任意ページまでの本文から
800〜1,500字のrecapを生成してbook / `up_to_page`単位でcacheできれば完了とする。

### B-25. meta2.dbバックアップの外部複製・復元運用

**現在地**: `sqlite3.backup()`による外部ディレクトリ向けsnapshot APIと、Linuxの世代backup・復元試験は
実装済み。外部ストレージからの明示復元と端末間の衝突処理は未実装である。

**次の一手 / 完了条件**: 検証済み世代だけを外部ストレージへ複製し、衝突policy、暗号化、世代保持、
復元前previewを確定する。ライブDBを同期領域へ置かず、明示操作で復元試験まで完走できれば完了とする。

<a id="b-37"></a>
### B-37. page-level LanceDB ICUへの段階移行 — 実利用観測待ち

**現在地**: 段階切替、整合検査、fallback、固定評価は完了し、既定は`fts5`のままである。

**次の一手 / 完了条件**: 自然な実利用shadow queryを
[検索QA設計 §10](../../design/詳細設計/機能別/小説RAG_検索QA設計.md#rag-search-evaluation)の条件で観測する。
合格後も自動昇格せず、利用者の別承認後に`lance_icu`切替とFTS5 rollbackを再確認して完了とする。

正本は[検索QA設計 §10](../../design/詳細設計/機能別/小説RAG_検索QA設計.md#rag-search-evaluation)と
[ADR-0020](../../design/基本設計/ADR/0020_page-level-lancedb-icu-shadow.md)。dense model、reranker、embedding置換は含めない。

<a id="b-35"></a>
### B-35. 小説OCRの機械単独自動公開 — 保留

**現在地**: 機械単独候補は正式policyに未達で、自動公開を停止中。Codex原画像レビューと明示公開を伴う
隔離運用だけを条件付き採用している。

**次の一手 / 完了条件**: ページ最大CERを下げる新しい独立候補・仮説を固定した場合だけ、
[OCR実装計画](小説OCR品質改善_実装計画.md)の新規未調整holdout工程を再開する。同計画の全gate、
画像照合QA、公開・rollback契約を満たすまで機械単独自動公開を実装しない。

詳細工程と受入条件は[OCR実装計画](小説OCR品質改善_実装計画.md)、
現行契約は[OCR設計書](../../design/詳細設計/機能別/OCR設計書.md)を正本とする。
候補別の実測・完了工程は[整理前記録](../../archive/検証/要件・バックログ_整理前_2026-09-05.md)を参照する。

<a id="b-36"></a>
### B-36. 既存要約・人物辞典の再生成とQA — 保留（現方式不採用）

可読性優先promptで既存生成物を更新する候補。OCR本文・画像・索引を変更せず、隔離成果物、機械gate、
独立評価、人手承認を通った場合だけ公開する。失敗時は旧公開版を保持する。

**現在地**: 全巻本文から直接fact graphを生成する旧候補は不採用で、旧公開版を維持している。
原子的な行為fact抽出、全factの独立評価、文章化、完成文評価を分離する改訂案は設計済みだが、
新しい評価として再開する受入判断はない。

**次の一手 / 完了条件**: 再開する場合は[Sol導入計画](Sol生成・評価_導入計画.md)に従って対象冊数、
停止条件、利用量上限を別承認する。現行の[Sol生成・評価設計](../../design/詳細設計/機能別/小説RAG_Sol生成・評価設計.md)の
全fact supported、完成文評価、人手承認を満たすまで文章化と公開DB置換を行わない。

関連する設計判断は
[ADR-0018](../../design/基本設計/ADR/0018_sol-primary-post-ocr-generation.md)。モデル別の全実測は
[整理前バックログ](../../archive/検証/バックログ_2026-08-22_整理前.md)と
[小説RAG検証履歴](../../archive/検証/小説RAG_技術検証履歴.md)を参照する。

## 対象外の原則

個人LAN・単一利用者・同人誌特化という前提から、認証／マルチテナント、公開API向けrate limit、
microservices、Kubernetes、GraphQL、外部クラウドLLMへの自動送信は対象外とする。
撤去済みタグやシリーズ自動生成、ePub、レーティングも、利用要件が変わらない限り再導入しない。
個別判断の履歴は[整理前バックログ](../../archive/検証/バックログ_2026-08-22_整理前.md)を参照する。
