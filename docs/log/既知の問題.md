# 既知の問題

## 新旧Kindle併用時に撮影対象の補助ウィンドウを誤選択する

- **確認日・影響**: 2026-10-07。旧版の小さな`Kindle`補助windowをタイトル検索で
  選択し、新版の本文座標と撮影windowが不一致になった。起動状態によっては黒い小窓が写り込む。
- **回避**: 利用しない版を終了し、表示windowの識別情報・ASINと保存先頭画像を照合する。
  不整合・写り込みを確認したjobは登録せず、新規jobで取り直す。
- **解消条件 / owner**: project owner。常用agentの選択と新旧切替を実装・実機検証する。
  補助取得での回避を、恒久修正済みとは扱わない。
- **記録**: [実機知見](技術知見/Kindle自動撮影_実機知見.md#kindle-window-selection)。

## 撮影・操作終了後にマウスカーソルが非表示になることがある

- **報告・影響**: 利用者から、処理終了後もマウスを動かしても矢印が見えないと報告された。
  後続のマウス操作時に復帰したが、原因は確定していない。
- **現状**: 撮影前の操作カーソル除去、撮影中の補助プロセス操作の回避、
  終了後のライブラリ復帰・通常操作確認を補助手順とする。
- **解消条件 / owner**: project owner。操作セッションの終了から復帰までを再現し、
  カーソルが見える状態へ確実に戻ることを実機で確認する。
- **記録**: [実機知見](技術知見/Kindle自動撮影_実機知見.md#kindle-cursor-lifecycle)。

## 停止中の旧 Windows サービス登録は管理者再登録待ち

`scripts/setup_service.bat` と設計書は uv workspace のルート `.venv` へ統一済み。
一方、現在の `Pic2PDFViewer` Windows サービスは停止・無効化された旧登録で、
`backend/.venv/Scripts/python.exe` を参照している。

- **影響**: Linux 本番と通常開発には影響しない。無効化されたサービスを
  そのまま再有効化した場合だけ旧環境へ依存する。
- **解消条件**: Windows サービスを再利用するとき、管理者として
  `scripts/setup_service.bat` を実行し、登録先がルート `.venv` であることを確認する。
