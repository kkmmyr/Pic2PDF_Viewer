## 2026-06-16: fix — Kindle 新アプリ（Microsoft Store 版）対応（TM-1）

新 Kindle for Windows（Microsoft Store 版）のウィンドウタイトルが `'Kindle for PC'` → `'Kindle'` に変わったため `kindle-pdf/capturer.py` を修正。診断スクリプト（`diagnose_new_kindle.py`）で `GetWindowDisplayAffinity = WDA_NONE`（保護なし）・`ImageGrab` 正常取得を確認済み。変更点は 3 箇所: `KINDLE_WINDOW_TITLE = 'Kindle'`、`TITLE_PATTERN` を旧新両形式対応の `(?:Kindle for PC\d*|Kindle)\s*-\s*(.+)` に更新、`find_window()` のマッチ方式を `in` → `startswith` に変更（VS Code 等への誤マッチ防止）。TM-1 完了。
