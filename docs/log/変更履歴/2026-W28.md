ライトノベル系「ふつつかな悪女ではございますが」での再検証 6 回で判明した 2 つの不安定性を修正し、層1全合格（M1 3,105 字 / M2-M5 合格）に到達。

- **M4 検出強化**: 簡体字セットに 评・级・绝・纯 を追加（「评分」が素通りした実測に基づく。いずれも日本語新字体に同形なし）。台本ステップの言語ルールにも「trope 等の英語批評用語は日本語で言い換え、作品タイトル固有名詞は可」を明記（`discussion_checks.py` / `discussion_prompts.py`）。テスト 55 件緑。

## 2026-07-07: fix — B-28 DoD 層3 フィードバック反映（OPフック導入変更・構成メモ JSON リトライ）

「後宮の烏」の層1全合格台本に対するユーザー層3判定は S2（キャラ一貫性）合格・S1（笑える/へえ 3+）は「内容がまじめすぎて人を選ぶ」→ ライトノベル系（ふつつかな悪女ではございますが）で再検証する方針に。あわせて 2 点を修正:

- **OPフックの導入方法を変更**（ユーザー要望）: 「〇〇だと思って敬遠してる人、損してます」型の書名直入りから、最初の 1〜2 ターンは本に触れない身近な話題・雑談から始めて自然に本へ接続する形へ（`discussion_prompts.py`）。
- **構成メモ JSON の自動リトライ**: 「ふつつかな悪女」初回生成で構成ステップの JSON 出力が崩れ、1 回のパース失敗で全体が error 終了する堅牢性ギャップが発覚。`generate_plan` にパース・バリデーション失敗時の同一プロンプト再試行（最大 3 回、`_PLAN_MAX_ATTEMPTS`）を実装。KV cache により再試行コストはほぼゼロ。テスト 2 件追加（リトライ成功・全滅時の試行回数）で計 38 件緑。
