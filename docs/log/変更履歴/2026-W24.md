## 2026-06-12: fix — PDF リーダー中央クリック時にヘッダー/スライダーが表示されないバグ修正

**変更内容**:
- `frontend/src/index.css` に `@layer utilities` ブロックを追加し、カスタム z-index クラスを明示定義
- `ReaderHeader` の `onMouseLeave={showHeaderOff}` を削除（補助的な修正）
- `PageSlider` の `onMouseLeave` プロップ（`showSliderOff`）を削除（補助的な修正）

**根本原因**: Tailwind v4 の JIT は `@theme` に定義した `--z-header: 50` 等の非数値 z-index トークンから `.z-header { z-index: 50; }` クラスを自動生成しない。そのため `z-header` / `z-overlay-bar` / `z-dialog` 等を使っていた全コンポーネントで `z-index` が `auto` になり、DOM 上で後に来るコンテンツ div に覆われて不可視になっていた。ヘッダーは完全不可視、スライダーは一瞬だけ見えていた非対称な挙動も同一原因。

**修正**: `@theme` のトークン定義は維持したまま、`@layer utilities` で 7 クラス（`z-card-badge` / `z-floating-action` / `z-overlay-bar` / `z-header` / `z-toast` / `z-dialog` / `z-dialog-nested`）を `var(--z-*)` 参照で明示登録。値の一元管理を維持しつつ CSS クラスが確実に出力されるようにした。
