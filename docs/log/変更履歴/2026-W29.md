## 2026-07-19: fix — 新Kindleの全頁キャプチャ安定化

- Microsoft Store版Kindleの実機で、F11中にページ送りすると本文が白画面のままになる一方、最大化ウィンドウでは正常描画されることを確認し、新版だけ最大化方式へ変更。
- 新版のページ送りを反応しない矢印キーから画面左右ボタンのクリックへ切り替え、旧Kindle for PCのキー操作は互換維持。
- ページ変化直後の遷移フレームを保存せず、同一画像が一定時間継続してから保存する安定判定を追加。
- 表紙などページ番号外の画像を含む期待撮影画面数を任意指定可能にし、指定数未満の無変化停止を正常完了と扱わない設計へ変更。Kindleの紙面ページ数と画面送り回数は一致しないため通常は自動終了を使う。
- 新版の上部ツールバー、下部進捗バー、左右ページ送りUIをキャプチャ範囲から除外。
- 実書籍（紙面ページ1〜265 + 表紙）を2回独立に全97画面取得し、同番号同士のpHash差が中央値0・最大2/64であることを確認。正式結果は最終画面がページ265/265、連番97件、SHA-256重複なし、全件3516×1918px（幅×高さ）、全面白画像なし。
- OCR/DBの`page_no`は紙面ページ番号ではなく連番PNGのキャプチャ画面番号であることを正本化し、診断・中断フォルダを`images/`外へ隔離してからOCR投入する運用を追加。
