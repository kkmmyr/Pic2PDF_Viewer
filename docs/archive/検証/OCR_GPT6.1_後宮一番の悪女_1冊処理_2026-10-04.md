# GPT-6.1『後宮一番の悪女』1冊処理

> status: frozen | verified: 2026-10-04

『後宮一番の悪女 (富士見L文庫)』の80キャプチャ画面を、初回画像OCR、全文レビュー1回、
独立全文画像QA、固有名詞の全出現字形確認、追加補正1回まで処理した。
最終本文・あとがきは95,611字。確認済みの未補正指摘・本文の判読留保は0で、今回の運用上の採否条件を満たした。
レビュー1回と全文QAだけでは固有名詞の共通誤読が残り、追加の字形確認が必要だった。
正式CER・未知書籍での完全性・製品への取り込み完了を意味しない。最終候補はローカル保存、未公開。

## 対象・事前条件

前回の[24画面のレビュー補正検証](OCR_GPT6.1_レビュー補正_1冊検証_2026-10-04.md)より長い別の本を選んだ。
保存済み小説の数値PNG画面数順で、前回の24画面短編と既に公開済みの57画面書籍を除き、
次の80画面の本を画像品質を見る前に決めた。原画像は3516×1940 PNG、連番1〜80。
本文70画面、あとがき1、表紙・扉・権利・目次・広告・奥付・終端ロゴ9画面。
目次の印刷ページ数とキャプチャ画面数は区別する。

原画像を`medaroserver`から読み取り専用で取得し、全80画面のSHA-256をサーバー側と照合した。
各画面の右・中央・左の全高overlap crop計240枚は、原画像と画素一致し、全幅を覆うことを検証した。
既存OCR run 71は`awaiting_qa / pending / model=unversioned`、canonicalの書籍は未登録だった。
状態メタデータのみ読み、既存OCR本文は参照していない。正式な未開封holdoutではない。

処理前の`plan.json`で、全80画面の可読出版文字を原画像照合し、画像・親候補SHAが一致すること、
文・段落欠落、意味置換、固有名詞誤り、未解決本文、原画像で確定した軽微指摘を残さないことを採否条件にした。
追加補正は最大2回まで。表紙下端の撮影時に切れた非本文文字は別途留保し、未知文字を創作しない。
独立人手正解全文がないため、診断的文字差異率やCERの数値基準は今回の成績として算出しない。

## 手順・独立性

担当には`gpt-6.1-sol / high`を指定し、各担当の書込み先を分離した。主担当が裁定・統合・最終検証を担った。

1. 初回担当3名が1〜27、28〜54、55〜80を画像だけから転記。原画像と全3cropを実表示し、全列を処理した。
2. 主担当が1〜15、新しいレビュー担当3名が16〜27、28〜54、55〜80を確認した。
   初回担当のcompletion注記、既知誤り一覧、他候補、以前の監査、Webは渡さない。
   原画像で確定した一意の`before→after`だけを1回のレビュー別版へ保存した。
3. 新しいQA担当3名が1〜27、28〜54、55〜80を全列照合した。各画面で原画像・全3cropを先に表示し、
   その後、レビューJSONの本文・非本文・分類だけを表示した。changes・notes・留保一覧・completionは読ませない。
   前回24画面のような別の全文参照転記を事前固定する方式ではなく、実際の1冊を仕上げる運用QAである。
4. 主担当が本文の人名・国名表記ゆれを抽出した。新しい字形監査担当には候補・既知誤りを渡さず、
   対象14画面の画像だけから国名7出現・賢妃名31出現を転記させた。
   全38出現の局所cropを5倍nearest-neighborで表示し、元画素一致を検証した。
   自分で見立てたUnicodeの明朝字形と構成画も比較し、振り仮名・辞書・多数決による補正はしない。
5. 主担当も38出現の原画像cropと字形比較を表示して裁定。確認した32箇所を最終別版へ1回だけ適用した。
   初回・レビュー・QAは固定し、最終版80件・全文TXT・未公開bundleと親SHAを保存した。

段階は一部並行した。入力manifest作成09:25:00 UTCから最終候補保存10:21:02 UTCまでは約56分。
これは観測された経過時間であり、各段階の時間の単純合算、課金量、人の確認作業時間には換算しない。

## 運用上の判断・限界

今回の1冊では、全文レビュー、全文原画像QAに、**書籍全体の固有名詞表記ゆれ抽出と画像だけの全出現字形確認**を
加え、事前の許容基準まで仕上げられた。文章・段落の欠落や読順崩れは今回の全列QAで確定されなかった。
ただし原画像QAにも共通誤読・誤検出がある。自然な本文や候補一致を根拠に自動採用すると、固有名詞誤りを残すか、
正しい文字を壊す。表記ゆれは確認対象を探すために使い、正解の決定は原画像の構成画で行う。

人手GT、独立全文参照、未知書籍holdoutはない。正式CER・H3・未知長編での完全性・自動採用可否は未判定。
印刷どおりの不自然な語句、引用符の欠落、末尾読点等は創作的に修復していない。
表紙下端で撮影時に切れたレーベル文字は、出版本文と分けて留保した。

既存Qwen+dotsのreviewed-package importerは今回のGPT6.1成果物schemaを受け付けないため、
provenanceを偽装して取り込んでいない。DB・canonical・索引・公開契約・アプリコードは変更していない。
終了時にも読み取り専用照会でcanonical未登録と既存run 71の状態維持を確認した。
