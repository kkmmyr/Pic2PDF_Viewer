---
description: バックエンド (pytest) とフロントエンド (vitest) のテストを順次実行する
---

以下を順番に実行してテスト結果を報告してください。

1. **バックエンド**: `cd backend && uv run pytest`
2. **フロントエンド**: `cd frontend && npm run test -- --run`（vitest watch を使わない一発実行）

各実行の最後の数行（テスト件数・パス/失敗・実行時間）を報告すれば十分です。すべての出力を貼り付ける必要はありません。

どちらかが失敗した場合：
- 失敗したテスト名と原因の要約を報告
- 修正を提案するだけで、勝手に実装はしない（ユーザーの判断を仰ぐ）
