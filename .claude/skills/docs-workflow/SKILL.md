# ドキュメント連動の変更手順

手順本体・スキップ条件は **CLAUDE.md「タスク完了後の必須アクション」が正本**。本 skill はそこでは書ききれない「どの設計書に何を書くか」の振り分けだけを補足する。

## 設計書の振り分け

- 仕様変更 → 要件定義 / 基本設計
- 実装方針 → 詳細設計
- API → API.md（+ `/openapi.json`）
- データ保存 → 詳細設計 + セキュリティ設計書

該当設計書の所在は `architecture-overview` skill の一覧を参照。

## hook との関係

`remind_docs_update.sh` (PreToolUse) が同じ方針を編集直前に **advisory** として短く通知する。hook は機械的トリガー、本 skill は振り分けの中身、CLAUDE.md が手順・スキップ条件の正本。
